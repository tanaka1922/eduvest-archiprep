# EduVest 二級建築士 学科対策（ArchiPrep）

二級建築士の学科試験（計画・法規・構造・施工）を、分野ごとに練習するためのWebページ集です。

- `index.html`：入口
- `planning.html`（計画）、`regulations.html`（法規）、`structure.html`（構造）、`construction.html`（施工）
- 問題データ：`questions.json`、`data/`

A practice site for the Japanese 2nd-class architect exam (planning, regulations, structure, construction). Plain HTML + JSON.

Made by EduVest Technologies. For learning purposes.
